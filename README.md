## Project Summary

### 1. Portfolio Foundations (Devoir 1)
The cornerstone of this journey. This project focused on **visual hierarchy**, whitespace management, and smooth transitions inspired by Apple's minimalist aesthetic.
*   **Key Learnings:** Mastery of CSS variables, Intersection Observer API for "reveal" animations, and WCAG accessibility standards (Contrast & Scale).
*   **Technique:** Establishing a "Cloudy Pastel" palette to reduce ocular fatigue while maintaining a premium feel.

### 2. User-Centered Design: White Blood Hub (Devoir 2)
An Esports service platform dedicated to *Splatoon 3* and *SSBU*.
*   **Services Offered:** 
    *   **Gold Blood Training:** Pro-level coaching for competitive players.
    *   **Arena Access:** Competitive match room reservations.
    *   **Chill Mode:** Private sessions for friends and family.
*   **Key Learnings:** Developing **User Personas** and **Scenarios**. Transitioning from low-fidelity wireframes to a functional service booking system.
*   **GitHub Link:** [kr1s3van/whiteblood-hub](https://github.com/kr1s3van/whiteblood-hub)

### 3. Interactive Logic: Pixel Memory Quests (Devoir 3)
A retro-inspired memory game designed to test cognitive spatial recall.
*   **Key Learnings:** State management in React, neighborhood algorithms for random path generation, and **Gestalt Laws** (Similarity, Proximity, Continuity) to guide user focus.
*   **GitHub Link:** [kr1s3van/pixel-quest-memory](https://github.com/kr1s3van/pixel-quest-memory)

### 4. Advanced Systems: Pixel Island E-commerce (Devoir 4)
A complex e-commerce prototype themed around *Animal Crossing*.
*   **Features:** **Faceted Search** (filtering by platform/format), a multi-step checkout process ("Following Instructions"), and a post-purchase feedback survey.
*   **Key Learnings:** Application of **Nielsen's 10 Usability Heuristics**. Focus on the "System Image" vs. "User Mental Model" and conversational UI.
*   **GitHub Link:** [kr1s3van/pixel-island](https://github.com/kr1s3van/pixel-island)

### 5. Data Viz & i18n: Pixelboard (Devoir 5)
An interactive bilingual dashboard for retro gaming market analytics.
*   **Features:** High-performance data visualization with Recharts, parameter switching (CAD/USD), and dynamic filtering (Top 3 Consoles).
*   **Key Learnings:** The **3Cs of Data Visualization** (Context, Clutter-free, Contrast) and **Internationalization (i18n)** strategies.
*   **GitHub Link:** [kr1s3van/pixelboard](https://github.com/kr1s3van/pixelboard)

## Core UX/UI Concepts Mastered
*   **Heuristic Evaluation:** Systematic analysis of interface friction points.
*   **Information Architecture:** Organizing complex data through faceted exploration and split layouts.
*   **Cognitive Load Reduction:** Using whitespace, "Scroll Snapping", and simplified user flows.
*   **Localisation:** Designing flexible interfaces that adapt to multiple languages and cultural contexts.
